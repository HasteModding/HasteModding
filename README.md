# HasteModding

This Github organisation exists to give mod developers a place to host the source code for their Haste mods, aswell as acting as a central source of information to help developers create mods, and help users use them

This Github organisation is completely maintained and run by the community. It shares no affiliation with Landfall or its games, and is not publicly endorsed.


## Rules

1. Do not obfuscate any content. This applies to the code in it's source and compilled form.
2. Do not release malicious code. This applies to code intended to harm Landfall or any user's of mods.
3. Do not infringe copyright. You should respect both Landfall's and any other individuals copyright.
4. Do not upload decompilled mods. You should respect the licensing of every mod, propietary or otherwise.

## Adding mods

If you wish to have the source code of your mod added to this organisation, you have two options:

1. Have the source code hosted in the organisation
2. Have a fork of your source code made by the organisation

Both of these options either require applying for membership, or, trusting pre-existing members.

---

## To apply for membership

1. Create an issue on this repository, with the "Application" template.
2. Fill out the template.
3. Wait for a pre-existing member to approve your access.

## To have your source code forked

1. Create an issue on this repository with the "Fork request" template.
2. Fill out the template.
3. Wait for a pre-existing member to fork your repository.

---

## Notes

This organisation does not serve as an alternative to Haste's Steam Workshop integration. It exists to allow developers to share the source code for their mods within a centralised space, in order to make organisation easier, and to help developers find existing examples of mods.
